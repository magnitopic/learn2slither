# learn2slither

A snake that learns how to behave in an environment through trial and error.

## Keybindings

| Keyboard                | Action                              |
| ----------------------- | ----------------------------------- |
| `↑`                     | Move up                             |
| `←`                     | Move left                           |
| `↓`                     | Move down                           |
| `→`                     | Move right                          |
| `Space`                 | Toggle game movement (Pause/Resume) |
| `d`                     | Step by step, one turn              |
| `1`, `2`, `3`, `4`, `5` | Set game speed (default: 1)         |
| `Esc`                   | Exit the game                       |
